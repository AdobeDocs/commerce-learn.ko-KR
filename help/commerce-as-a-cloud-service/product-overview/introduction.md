# Adobe Commerce as a Cloud Service 소개

Adobe Commerce as a Cloud Service이 중앙 집중식 관리 및 모듈식 아키텍처를 통해 작업을 간소화하는 방법을 알아봅니다. AI 기반 개인화가 채널 전반에서 쇼핑 경험을 어떻게 향상시키는지 알아보십시오.

## 이 비디오는 누구의 것입니까?

* 전자 상거래 관리자
* 디지털 마케팅 전문가
* IT 솔루션 설계자

## 비디오 콘텐츠

* 중앙 집중식 관리 및 모듈식 아키텍처를 통해 Adobe Commerce as a Cloud Service을 보다 빠르게 확장하는 방법에 대해 알아봅니다.
* AI 기반 개인화가 여러 채널에서 원활한 쇼핑 경험을 제공하는 방법을 살펴볼 수 있습니다.
