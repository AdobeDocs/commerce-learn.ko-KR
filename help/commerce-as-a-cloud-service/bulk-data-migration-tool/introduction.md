# 대량 데이터 마이그레이션 도구 소개

도커를 준비하고 대량 데이터 마이그레이션 도구에 액세스하여 Adobe Commerce 데이터를 [!DNL Adobe Commerce as a Cloud Service]&#x200B;([!DNL ACCS])(으)로 마이그레이션합니다.

## 이 비디오는 누구의 것입니까?

* 솔루션 설계자
* DevOps 엔지니어
* 백엔드 개발자

## 비디오 콘텐츠

* 대량 데이터 마이그레이션 도구의 기능 및 제한 사항에 대해 알아봅니다.
* 시작하기 전에 도커가 설치되어 있고 도커 엔진이 실행 중인지 확인하십시오.
* 도구 패키지를 추출하고 올바른 폴더 권한을 설정합니다.
* 이 시리즈의 다음 비디오에 구성된 `.env.example` 파일을 검토하십시오.
