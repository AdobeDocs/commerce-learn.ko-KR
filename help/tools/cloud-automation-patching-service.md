# Adobe Commerce 패치 자동화

Adobe Commerce 패치 자동화 기능은 Adobe Commerce SWAT(Site Wide Analysis Tool)의 한 기능으로, 보안 패치를 찾고 적용하는 프로세스를 간소화합니다. 사용자는 SWAT 대시보드 아래의 Commerce 관리를 통해 패치 자동화 기능에 액세스하고 프로젝트 및 환경을 선택하고 사용 가능한 패치를 확인합니다.

## 이 비디오는 누구의 것입니까?

* 웹 사이트 관리자
* 개발자
* DevOps 및 시스템 관리
