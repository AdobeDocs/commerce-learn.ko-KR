# Adobe Commerce용 IO 이벤트 시작하기

Adobe I/O Events에 대해 알아봅니다. 이 데모에서는 Adobe Commerce의 이벤트가 Adobe Developer App Builder을 사용하여 Slack 채널로 전송됩니다.

## 이 비디오는 누구의 것입니까?

* Adobe Commerce 및 Adobe I/O Events을 사용하여 이벤트 기반 애플리케이션을 구축하는 방법을 학습하는 개발자.

## 비디오 콘텐츠 {#video-content}

* Adobe I/O Events에 대해 알아보기
* Amazon EventBridge를 비롯한 Adobe I/O Events의 다양한 엔드포인트 이해
* App Builder 프로젝트 설정 및 구성 방법 알아보기
* CLI에서 Adobe I/O 명령 사용
* 이벤트 처리를 위한 런타임 작업 만들기
* Adobe Commerce에서 Slack 채널로 이벤트 보내기
