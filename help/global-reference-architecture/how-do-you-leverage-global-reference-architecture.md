# 글로벌 참조 아키텍처 활용

글로벌 참조 아키텍처 또는 GRA를 활용하는 방법을 알아봅니다. 성공적인 구현을 위한 GRA를 보다 잘 준비하기 위해 Adobe 전문가들은 프로젝트의 다양한 단계에 대해 논의하고 검색 단계에 대해 자세히 설명합니다. QA 리소스에 대해 논의하고 GRA 구현에 귀중한 리소스인 이유를 설명합니다.

## 대상자

* 이 개념을 이해해야 하는 모든 사람.
* 여러 브랜드를 사용하는 대형 프로젝트

## 비디오 콘텐츠

* GRA 구현의 이점
* 요구 사항 수집
* QA 팀은 언제 참여합니까
