# Adobe Commerce 개발자 에이전트 배포, 연결, 설치

모든 것이 연결된 상태에서 앱을 배포할 준비가 되었습니다. 이 단계에서는 코드를 배포한 다음 저장소에서 새 기능이 활성화되도록 Adobe Commerce 관리에 코드를 연결 및 설치합니다.

## 이 비디오는 누구의 것입니까?

* Commerce 개발자
* 솔루션 설계자
* Commerce 관리자

## 비디오 콘텐츠

* 개발자 에이전트에게 채팅에서 배포하도록 요청하고 정확한 조직, 프로젝트 및 작업 영역을 확인합니다
* 배포 전 유효성 검사를 통과한 다음 코드가 배포될 때 빌드 및 게시 출력 스트리밍
* Commerce 관리자의 앱 관리 화면에서 배포된 앱을 특정 스토어에 연결
* 앱 카드 검토 - 이름, 버전 및 앱 카드가 추가하는 기능(웹후크)
* 앱을 설치하여 기능을 활성화하고 성공적으로 설치되었는지 확인
