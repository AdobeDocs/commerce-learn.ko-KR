# Adobe Commerce 개발자 에이전트 기존 코드 마이그레이션

모든 프로젝트가 빈 구성에서 시작되는 것은 아닙니다. 이 예에서는 마이그레이션 평가 도구를 사용하여 개발자 에이전트를 제공하고 기존 확장을 App Builder으로 마이그레이션하고 PaaS 플랫폼에서 Adobe Commerce as a Cloud Service으로 이동합니다.

## 이 비디오는 누구의 것입니까?

* Commerce 개발자
* 솔루션 설계자
* 백엔드 엔지니어

## 비디오 콘텐츠

* 마이그레이션 평가 도구를 사용하여 기존 Commerce 인스턴스 스캔 — 복잡성 등급, 모듈별 영향, 위험 신호, 권장 사항 재구성, 리팩터링, 교체 또는 제거
* 후크, 파일 및 준비된 프롬프트의 두 배가 되는 일반 언어 목적 요약을 포함하여 영향력이 큰 모듈의 평가 검토
* 수동으로 복사하지 않고 Developer Agent에 평가 전송
* 첫 번째 단계에 특정 기능에 집중하려면 에이전트의 범위 관련 질문에 답하십시오.
* 가장 위험한 레거시 논리를 아키텍처 다이어그램으로 대체하는 동기식 웹후크의 블루프린트 생성
* 각 처리기와 함께 작성된 일치하는 테스트 파일로 구현 구축
