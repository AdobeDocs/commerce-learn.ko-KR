# Adobe Commerce 개발자 에이전트 블루프린트 및 개발 단계

블루프린트 및 개발 단계는 일반 영어 규칙이 유효성이 확인된 코드가 되는 단계입니다. Adobe Commerce 개발자 에이전트는 장바구니 수량 제한을 예로 사용하여 설명된 규칙을 검토할 수 있는 공식 플랜으로 전환한 다음 라이브 작업 공간에서 웹후크 코드를 작성하고 자체 확인합니다.

## 이 비디오는 누구의 것입니까?

* Commerce 개발자
* 솔루션 설계자
* 백엔드 엔지니어

## 비디오 콘텐츠

* 비즈니스 규칙(장바구니 수량 제한)을 일반 언어로 설명하고 App Builder 모드에서 블루프린트 생성
* 블루프린트 및 계획 패널 검토 - 런타임 선택, 엔터프라이즈 준비 체크리스트 및 신뢰도 예측
* 구체적인 작업으로 분류된 계획과 웹후크가 장바구니 추가를 평가하고 차단하는 방법에 대한 논리 다이어그램
* 개발 단계는 프로젝트 작업 공간에 파일 및 코드 스트리밍과 함께 코드를 작성합니다
* 자동 빌드, 테스트 및 자체 수정, 설명이 필요한 경우 에이전트 일시 중지
* 생성된 구성, 비즈니스 구성 스키마 및 웹후크 세부 정보의 유효성 검사
