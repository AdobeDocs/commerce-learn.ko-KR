# Adobe Commerce 개발자 에이전트 개요

Adobe Commerce 개발자 에이전트는 일반 영어 요청을 손으로 작성한 코드 없이 작동하는 배포된 스토어 기능으로 전환합니다. 이 개요에서는 형식화된 단일 지침에서 실제 상점에서의 라이브 테스트까지 전체 여정을 살펴보고, 사용자 지정 Commerce 기능이 구성되는 방식이 변경되는 이유를 설명합니다.

## 이 비디오는 누구의 것입니까?

* Commerce 개발자
* 솔루션 설계자
* 개발 리더

## 비디오 콘텐츠

* 사용자 지정 Commerce 기능이 일반적으로 필기 웹후크 코드, App Builder 설정 및 전체 빌드-테스트-배포 주기가 필요한 이유
* 개발자 에이전트가 일반 영어 규칙에서 기술 구현(올바른 웹후크 메서드, 페이로드 매핑 및 구성 스키마)을 처리하는 방법
* 사람이 디버거를 열기 전에 빌드 오류를 감지하고 수정하는 자동 코드 유효성 검사
* 시작 후 스토어 팀이 조정할 수 있는 비즈니스 구성으로 제한 및 메시지 노출
* 블루프린트, 개발, 연결, 배포, 구성 및 테스트 전체 연습의 미리보기
