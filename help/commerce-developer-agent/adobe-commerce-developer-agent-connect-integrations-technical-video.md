# Adobe Commerce 개발자 에이전트 연결 통합

생성된 코드에는 실행할 위치와 스토어에 대한 연결이 필요합니다. 이 단계는 기능이 활성화되기 전에 App Builder에서 코드를 호스팅하고, Adobe Commerce 인스턴스에 연결하고, GitHub 리포지토리를 연결하는 모든 작업을 통합합니다.

## 이 비디오는 누구의 것입니까?

* Commerce 개발자
* 솔루션 설계자
* 백엔드 엔지니어

## 비디오 콘텐츠

* 개발자 에이전트가 만든 코드를 호스팅할 App Builder 프로젝트 및 작업 영역 만들기
* 에이전트 스캐폴드 보기 프로젝트 및 미해결 설정 항목 표시
* 개발자 콘솔에서 필요한 Adobe Commerce as a Cloud Service API 자격 증명 추가
* 특정 Adobe Commerce Cloud Service 인스턴스에 코드 연결
* 코드를 저장하고 버전을 지정하려면 GitHub 저장소를 연결합니다
